# Pre-Merge Quality Gate

- [ ] Change has a clearly stated purpose.
- [ ] Public behavior and edge cases are defined.
- [ ] Tests cover the intended behavior and relevant regressions.
- [ ] New tests are registered with CTest.
- [ ] Full build succeeds on supported compilers.
- [ ] Full CTest suite passes.
- [ ] No unrelated generated files or binaries are included.
- [ ] Error behavior is consistent with the existing CLI/API contract.
- [ ] Documentation is updated when behavior or commands change.
- [ ] Performance claims include a reproducible workload and measured results.

A checklist item must not be marked complete without evidence from the corresponding check.
